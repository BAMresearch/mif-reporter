# MIF Reporter

MIF Reporter helps document mechanochemical experiments before, during, and after synthesis. It can load existing records and export reaction documentation as MIF or JSON.

Open `index.html` in a browser. Use a standard experiment as a guide, enter your own observations, and review the record before exporting it.

The tool runs in your browser. Imported files and form data are not uploaded by MIF Reporter. This release is a single, self-contained HTML file and needs no build step.
